CREW GTA 6 — règlement statique

Fichier principal : index.html

Personnalisation :
1. Ouvrez index.html dans un éditeur de texte.
2. Remplacez le href="#" du bouton « REJOINDRE LE DISCORD » par votre invitation Discord.
3. Vous pouvez modifier les textes des règles directement dans le HTML.

Publication gratuite :
- GitHub Pages : créez un dépôt, ajoutez index.html, puis activez Pages dans Settings.
- Cloudflare Pages : importez le dossier ou connectez un dépôt Git.

Le site est autonome : aucune base de données, aucun abonnement et aucune dépendance externe.
